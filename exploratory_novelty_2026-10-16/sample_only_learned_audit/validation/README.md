The strict profile is guard-restored, not analytically inactive or safe: warm
prepaid claims may mature before margin processing. Both profiles retain all
twenty policies, all observed activity and all abstentions. The alpha=1 view is
a same-action booking ledger, rather than a separately redeployed policy. The
forward financial component excludes physical/battery flows and sunk warm costs;
it is not native RL reward, total fund return or complete lifecycle profit.

Conditional sign symmetry and deterministic supports are structural access
assumptions, justified by the instrumented native source and exact checks. Cached
records alone cannot prove independence of an untrusted simulator or give a
formal floating-point rounding proof. The declared numerical pad is an explicit
engineering allowance. Neither an arbitrary predictor nor local pairing is
guaranteed to reduce whole-path variance or obtain a positive certificate.

## Public confidence-arithmetic reproduction

The new, unfrozen `../public_export.py` refuses incomplete runs and requires a
complete passing private verification before producing `../results/<run_id>/`.
It leaves rich internal results unchanged. The public bundle contains only path
financial summaries, ordered coins and confirmation predictor differences,
frozen choices, scalar supports, all 520 numerical limits and relative SHA256
provenance. Actor observations, raw panels, private absolute paths, weights and
model pickles are excluded by a field whitelist.

The included `reproduce_public_native_audit.py` uses Python's standard library
alone. It checks every bundle hash and independently reconstructs the sequential
controls and all one-sided bounds. Its role is arithmetic reproducibility
conditional on the exported records, rather than native-engine reproduction.
No current financial endpoints have been exported while the run is partial.
The retained first `public_export_software_check_*` record and exact source
snapshots cover 23 literal arithmetic/support/control and incomplete-run refusal
checks. The later record `public_export_software_check_20261016T100643Z` passes 29
checks after independent review: it additionally rejects empty/missing/extra
mandatory hash sets and invalid persisted bytes, and verifies that the completion
manifest is published only after persisted-byte reproduction. The earlier record
and source bytes remain unchanged.
