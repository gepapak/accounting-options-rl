# Interpretation correction without numerical changes

Read-only manuscript review identified imprecise wording in the frozen plan:
it calls any positive full-charge limit a validation/control failure. Under the
declared no-edge law, full-charge expected value is nonpositive. A finite-error
confidence procedure nevertheless can produce a false positive. Any such outcome
must be retained, reported as a known-null false positive and investigated for
source/support errors. Its occurrence alone would not logically refute a
95% confidence theorem. The manuscript now uses this precise interpretation.

This note changes no frozen source, statistical decision, sample size, grid,
error allocation, policy, target or result. Certificate counts are descriptive
over this fixed benchmark; simultaneous coverage does not itself prove a
population-level learning-power advantage. Twenty archived policies crossed
with two profiles are forty cases, not forty independently trained policies.
