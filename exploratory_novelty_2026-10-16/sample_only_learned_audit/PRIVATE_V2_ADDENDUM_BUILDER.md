# Held local private v2 addendum builder

`prepare_private_review_v2_addendum.py` is NEW unfrozen packaging code. Its
default invocation prints `PREPARED_NOT_EXECUTED_WAITING_POST_RUN_RELEASE` and
creates no archive, reads no financial endpoint and imports no native code.
Its existence is not permission to run it while the primary experiment runs.
Root must release post-run work after workers exit and all checks finish.

The completed packet check is explicitly bound to
`replay_private_bundle_attempt4.py` and its current/executed snapshot SHA, using
`native_validation/clean_bundle_replay_attempt_4`. The original wrapper and all
failed attempts remain preserved. The compatible-packet eight-view cache PASS
and `native_validation/PACKET_PORTABILITY_VALIDATION.md` are included, with all
2880 actual replay native steps disclosed across attempts2–4. The previous
builder/checker bytes and hashes were preserved before this metadata update.
This update creates no archive and does not release the held builder.

The builder requires these completed records before packaging:

1. Original primary aggregation/confirmation markers and full independent
   `NATIVE_VERIFICATION_<run>_critics.json` PASS520, bound to its result/freeze
   and executed verifier source SHA.
2. Original auxiliary completion and full independent PASS240, bound to the
   unchanged auxiliary freeze, result, summary and executed verifier hashes.
3. Both completed eight-artifact public bundles and their saved standalone
   `REPRODUCTION.json` PASS records. The builder replays their standard-library
   arithmetic once more, after checking hashes. It never queries native actors,
   fitted critics, simulators or learners.
4. A released packet-only exact two-path software replay PASS with source,
   model, plan, module and golden-fixture identities, no original-native fallback
   or blocked access,192 audit and768 native warm-up transitions.
5. Completed descriptive report tables bound to both private PASS reports.
6. The separate descriptive control diagnostic's exact three-artifact output
   plus completion seal, bound to its executed source/plan, both private PASS
   reports, both public manifests/path hashes and original report completion.
   All240 records and12summary groups must retain256CONFIRM paths per case.
   This adds no confidence limit/family, fit, retuning or native query.

An eventual command, only after release, uses:

```powershell
python prepare_private_review_v2_addendum.py --execute --packet-replay-dir "<passed-packet-replay-attempt>" --coordinator-release "<root's recorded post-run release>"
```

Optional explicit roots are `--audit-root`, `--run-id`, `--base-folder`,
`--base-zip`, `--output-root`, `--archive-path` and `--completion-path`.
The output/archive/seal must be fresh and under the ignored local
`review_bundle_private/`; original source and v1 paths cannot be reused.
The builder requires the exact complete v1 ZIP SHA
`d96cf47f5d6746cf760608293bfbe5e62a5720f2b98c30702a89debf5f6b8299`,
checks all155 decompressed members and extracted files, and never modifies v1.

Every archive member begins `native_review_v2_addendum/`. Updated READMEs and
reviews go under `documents/`, not original base paths. Thus unpacking the
addendum beside v1 causes zero base-member collisions. A combined v2 archive
is not built; addendum plus preserved v1 suffices.

The fixed source/document lists include the auxiliary freeze/snapshots,
independent verifiers, public exporters/reproducers, portable cache helper and
retained literal attempts, chronology/state reports, latest software-compute
inventory, post-completion report source/fragments, interpretation/access notes
and conditional no-new-claims review. The latter remains explicitly conditional:
native executability/existence of a flat/no-new-claims reference is unproved.
Latest software inventories are as-of their timestamps; an earlier snapshot's
held-replay status is not silently changed by a later packet PASS.
The control-diagnostic source/plan and exact completed outputs are a separate
`descriptive_control_diagnostics/` layer. Its uncapped and same-learned-cap
sample comparisons are descriptive, not a new inference or superiority result.
The unrestricted-negative-tail boundary note is retained with its established
antecedents and stated target-class limits. Previous builder source/SHA and
literal attempts are preserved. Manuscript-only derivative tables remain excluded.

Both public numeric families retain their separate directories, hashes and
95% allocations; no joint95% claim is made. The only NPZ additions are the two
original `warm_attempt_2` software fixtures, PRIVATE with their observations and
original validation provenance. No scientific phase tree, raw market panel,
additional model/checkpoint ZIP, Keras file, critic pickle or fitted-model
bundle is added. The v1 packet already supplies its authorized exact inputs and
weights. Failed software sources/reports are retained without adding their
extra trajectory traces.

All copied files are individually hashed before and after copy; every source
is rechecked after ZIP creation. Low compression is used and existing gzip/NPZ
files are stored. The new ZIP is first written to an exclusive `.partial`, then
every decompressed member is rehashed before non-replacing publication. A
separate final `*_COMPLETION.json` binds the published archive hash, manifest,
member count, byte count, unchanged base/source identities and work. It is the
last artifact written. MANIFEST.json inside the ZIP is a contents record, not
the completion seal. Previous output/partial attempts are never overwritten.

This builder performs local private copying and arithmetic verification only.
It does not anonymize original metadata, assign artifact licenses, upload,
distribute weights, validate a clean dependency install, replay all40cases or
strengthen ordinary-market/AI-novelty claims. No archive has yet been built.
