# Methodological Protocols and Audit Documentation

Part of the codebase for the paper *"Reading hidden loss forgiveness from the reward of reinforcement-learning trading simulators, with an electricity-trading engine"* submitted to *Engineering Applications of Artificial Intelligence* (EAAI).

## Contents
- `METHODS_AND_RESULTS.md`: Comprehensive reference detailing mathematical models, experimental designs, empirical hypotheses, and headline findings.
- `PREREGISTRATION.md`: Frozen pre-registration document for the Prototype5 engine audit.
- `CODE_AUDIT_PROTOCOL.md` & `CODE_AUDIT_RESULTS.md`: Systematic protocol and coding results auditing 21 public electricity-trading RL repositories (evaluating capital accounting, price-taker assumptions, and solvency enforcement).
- `LITERATURE_SURVEY_PROTOCOL.md`: Protocol used for the systematic survey of peer-reviewed RL trading literature.
- `RUNNING_THE_CAMPAIGN.md`: Operational instructions for running and logging the 300-job scarcity tail campaign.
